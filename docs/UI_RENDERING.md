# ChemClient UI 渲染约定

适用于客户端 1.7.38。保留现有 Material Design 3 视觉；本轮修改组件生命周期、状态归属和窄屏布局。

## 修复范围

- 页面根节点及其子节点均带宿主 root / 实际页面命名空间，切页不复用另一页的原生节点。
- 布局标识由作用域、元素类型和调用位置构成，不再让整个作用域共用递增序号。条件提示或进度条不会改变后续独立控件的标识。
- 显式按钮/输入标识保留完整命名空间，不再被裸事件名覆盖。
- 只缓存当前构建使用的无子节点原型；离开页面、删除列表项后释放对应缓存。重复刷新不累计子节点和监听器。
- UI 事件携带页面代次。同页进度刷新保持代次；切页或更换宿主 root 后忽略旧页面排队的事件。换音频后的旧曲名输入也不会覆盖新文件。
- 状态提示明确属于模块管理、音乐、网易云、本地、曲库或 Magic；异步任务完成后按来源显示，不按用户当时正在看的页面显示。
- Magic 列表以资源包 folder 标识建立节点和事件。显示同名或删除前面的包不会串操作；实际发送时才解析当前索引，确认卸载后再次核对。
- 歌曲封面出现/消失时，标题保持相同父容器；安全模式操作改为纵向排列，模块工具栏允许窄屏换行。

## 后续修改

列表作用域必须使用业务标识。不要使用列表索引或可重复的显示名称作为资源标识。新增布局包装函数若要保持调用位置，应使用 `#[track_caller]`；复杂组件应有自己的稳定作用域。不要把已有子节点的 Element 存入 `UI_NODES`，也不要直接覆盖 `key`。

新增异步提示使用 `State::notice(NoticeOwner, message)`；错误归属在请求开始时确定。不要为了显示完成提示修改当前 tab。节点 `.on()` 统一使用 `event_id()`，由 `visible_event()` 检查来源页面。

## 验证与限制

`cargo test --locked --target x86_64-pc-windows-msvc -- --test-threads=1`

`ui_render_tests.rs` 构建实际页面树，覆盖反复切页、后台下载、条件区块、列表重排、同名资源包、旧页面点击、重新打开宿主和原型清理。测试适配器按 Astro API 4 的借用构建器修改后返回 owned clone 的行为实现；不链接或执行 WASM 宿主。

设置 `CHEM_UI_FIXTURES` 可导出页面树 JSON 做浏览器布局检查。浏览器预览检查由树生成的 HTML/CSS，不能代替 Astro 前端自身的组件协调、手机 WebView 和蓝牙实测。

本轮结果：89 项主机测试通过；Playwright 检查 8 种页面状态 × 320/390/768 CSS 像素宽度，24 组预览均无横向溢出；本地 API 4 / WASI 2 插件构建及打包校验通过。未在手机 Astro 宿主中验收。
