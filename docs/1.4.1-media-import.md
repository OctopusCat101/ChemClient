# ChemClient 1.4.1

2026-11-07

- Transfer ACK polling starts after25ms and backs off to50/100ms for slow writes. Keep one16KiB chunk in flight, existing request-ID retries, sequential offsets, CRC and atomic library commit.
- Encode the identical nested protobuf directly in one buffer, avoid cloning the full UI/search/library state per chunk, and use a16-entry incremental CRC table.
- Local MP3 imports use bounded ID3v2.3/v2.4 APIC extraction when no cover is selected. Explicit images take priority; embedded images are converted to96x96 NCV1 through the existing decoder limits. Audio is not loaded into memory. Existing songs without artwork need reimporting.
-17 host tests passed, including exact old/new protobuf bytes at varint boundaries, standard/segmented CRC and both ID3 versions. Release API4/WASI2 component and ABP built and validated. Real BLE throughput is not measured here.

Build: `python build.py --abp`. Distribution remains in this plugin's own `dist/`, referenced by the root `index.txt`.
